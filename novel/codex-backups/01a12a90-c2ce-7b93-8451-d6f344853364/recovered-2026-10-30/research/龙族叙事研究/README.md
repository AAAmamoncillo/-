## 引文与证据规约

`II｜序幕｜L743 / P348` 表示第二部原TXT第743行、文件内第348个非空行。L从1计；空白行也占行号。P是供稳定定位的“非空行段”，包括标题，不冒充排印版自然段；长行若含多句不再拆段。每个P与L的对应都在 `索引/paragraph_index.jsonl`。

原文的编码及SHA256保存在 `索引/source_manifest.json`。引用必须对应这一版本；文件变化后重建索引并记录差异。研究笔记不存全文副本，只保留必要短引及位置；源TXT保持不改。

读取示例（PowerShell）：

```powershell
python .\research\龙族叙事研究\tools\source_index.py --book II --start 1373 --end 1550
```

本工具仅输出原文；不会自动把输出过的文字标为已读。续读时先查进度，完整读完一个单元再登记。扫描标题、关键词命中、摘要和本来知道的剧情都不计入完整阅读。

## 后续每轮交付

以相邻的2—3个单元为目标；篇幅大时缩小批次，单元内部可分段，不能跳读。交付新增的阅读范围、人物/情节更新、1—2个值得精读的问题、得到反证的旧判断及下一入口。阅读中断时记录到行，不用假装一章读完。

正式跨卷结论及成体系的《魔女不会死》改稿建议，留到对应原作完整阅读后。此前的应用仅为检验方法的原创候选，不修改人物设定或正文。
