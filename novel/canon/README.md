## 版本优先级

最近明确确认的讨论覆盖旧设定；本次正文以本目录第 1–7 章为准。旧 20 章概要、旧大纲、后续试稿、聊天记录均为历史材料。其中与最新决定不冲突的基础规则可查阅，旧章号、旧续写起点和旧结局不能直接沿用。

- 王庭出身：莫伊伦是王庭的孩子，取消旧设定的私生子身份。七岁离开王庭，九岁忒索林出生；兄弟早年家庭与白银城的加雷特一家分开。
- 圣者线：真实救助在先，融合扭曲在后。庆典封锁及后续救护责任保留；具体高潮机制和章序不从旧大纲继承为事实。
- 维塔尔线：幻影属于莫伊伦的主观体验，无独立情报来源；形象年轻不等于只能使用死前的词与知识。家庭两案和袭击细节不在此定稿。
- 远期：莫成为魔女宿主若采用，须是偶然，不是圣者锁定目标；忒索林死亡的具体版本仍未统一。魔物威胁实际下降是已认可的世界变化，具体成因和尺度待写。
- 写作格式：段首两个全角空格，场景分隔用 ◇；角色知情以正文实际发生为准。试写里的练习、会面和查证不能替代新版铺垫。
